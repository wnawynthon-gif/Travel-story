Travel Guide Engine v2.2 — Vercel deploy check

REQUIRED repository structure:
/
  index.html
  app.js
  style.css
  manifest.json
  vercel.json
  package.json
  README.md
  api/
    guide.js

STEP 1 — is the function deployed?
  Open https://<your-app>.vercel.app/api/guide in a browser tab.
  JSON  -> the function exists. Check "hasKey": true.
  HTML  -> the api/ folder was not uploaded, or the build failed.

STEP 2 — environment variables (Vercel > Settings > Environment Variables)
  OPENAI_API_KEY     required. Paste with NO trailing newline/space.
  OPENAI_MODEL       optional, default gpt-5.6-terra
                     gpt-5.6-luna  = fastest / cheapest
                     gpt-5.6-terra = balanced (default)
                     gpt-5.6-sol   = flagship, slowest -> risks timeout
  OPENAI_EFFORT      optional, default low  (none|low|medium|high)
  OPENAI_MAX_TOKENS  optional, default 8000
  MAX_SECONDS        optional, default 55. MUST stay below maxDuration.
  After changing any of these: Redeploy.

STEP 3 — timeouts
  vercel.json sets maxDuration 60 (Hobby maximum without Fluid compute).
  If you enable Fluid compute you can raise it to 300 and set MAX_SECONDS=290.

NOTES:
- api/guide.js MUST stay inside the api folder in GitHub.
- The function always answers with JSON, never an HTML error page.
