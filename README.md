# Travel Story Engine v1.0

Starter mobile-first PWA.

## Files
- index.html
- css/style.css
- js/app.js
- manifest.json
- sw.js
- icons/

## Deploy
Upload the contents of this folder to a static web host such as Vercel or GitHub Pages.
After deployment, open the HTTPS URL in Safari on iPhone and use Share > Add to Home Screen.

## v1.0 scope
This starter creates and stores TSE workflow commands locally. AI/search/image generation is intentionally not connected yet; that is the next integration step.
